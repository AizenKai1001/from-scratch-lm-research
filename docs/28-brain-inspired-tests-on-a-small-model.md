# 28. Brain-inspired tests on a small model: graded neuron budgets, silent thinking steps, a lens, an ear cue and an eye

## What this is

Snapshot dated 7 November 2026. This document reports seven small tests that borrow an idea from how brains work and ask whether it helps, or at least costs nothing, in a small open language model. Five use Qwen3.5-0.8B; the two eye tests also use its larger sibling Qwen3.5-2B; the ear test uses no model. The 0.8B model is released under Apache-2.0, as its model card metadata states (**PUBLISHED**: [0.8B model card](https://huggingface.co/Qwen/Qwen3.5-0.8B)). The tests were run on consumer hardware, one at a time.

Each test had a written rule with fixed bars, fingerprinted (a checksum and a time) before its script ran. Treat every result as an indication, not a proof. Two tests (the neuron budget and the silent steps) failed their bars, and one (the lens) missed its bar. We report those as plainly as the passes.

Texts are public-domain books, pictures are generated by code or taken from a public photo set whose captions were typed by people, and the one audio test uses signals generated by code. No model-written text was used as an answer key anywhere. The labels are explained at the end.

## 1. Strong activations, surprise and cost of zeroing (test ACT-1)

**What we asked.** The feed-forward layers of a language model have thousands of activations per token. A brain fires more cells for a bigger or more surprising stimulus. Does the count of strong activations in this model do the same, with a fixed threshold and no training? And how much does the model lose if the weakest ones are set to zero?

**What we did.** We ran the 0.8B model on 8 blocks of 256 tokens of one public-domain book (2,040 scored tokens), with thresholds fixed on another public-domain book. For each token and layer we counted activations above the threshold at which half were zeroed, and correlated the count with the token's surprise (its own loss) and with the size of the layer input. We then zeroed the weakest 30, 50 and 70 percent and compared against zeroing the same share at random.

**What we found (FACT).** The correlation with surprise was slightly negative (mean over 24 layers -0.12). The correlation with input size was weak (+0.26). Zeroing the weakest activations cost little: +0.13 percent loss at 30 percent zeroed, +0.85 at 50 and +3.65 at 70, while zeroing the same number at random cost +47, +102 and +188 percent. Reading the model's guess at middle layers without training was poor: loss 13.1 after 6 layers, 12.7 after 12, 10.6 after 18 and 3.1 after all 24. The share of multiply-adds skipped in the second matrix of each feed-forward layer was 10.0 percent at 30 and 16.6 percent at 50 (**COMPUTED**; the first two matrices stay dense).

**What it does not show.** Nothing about speed. Skipping work on a small graphics card at batch size one is not shown to be faster.

## 2. A drive-set neuron budget (test DRIVE-1)

**What we asked.** Suppose the number of units kept active is not fixed but set per token by the size of the input and by the model's own surprise at the previous token. That would make activity scale with the stimulus and the model's own state, as the brain does. Does it lose less than a fixed budget at the same average?

**What we did.** Same text and model as above. Four arms at 50 and 70 percent zeroed: a fixed number per token; a number set by input size only; a number set by input size and previous-token surprise; the same drive shuffled among the tokens of a block (a control). Differences were bootstrapped over the 8 blocks.

**What we found (FACT).** Loss increase over the unmodified model, at 50 percent zeroed: fixed +0.92, size-only +0.91, drive-set +1.30, shuffled +1.33; at 70 percent: +5.14, +5.10, +4.85 and +5.33. The drive-set arm was not separated from the fixed arm (50 percent: the difference fixed minus drive-set was -0.37 points with an interval of -0.78 to +0.03) or from the shuffled control. The number of units kept ranged from 974 to 2,508 of 3,584 per token, so the budget did vary widely. It followed the input size almost exactly by construction, and followed the surprise of the current token only weakly (Spearman 0.10 at 50 percent zeroed).

**What it means (GUESS).** Letting the number of active units vary a lot with the input costs about the same as a fixed budget, so graded activity is available at no quality cost. This untrained rule gives no gain, and the written rule counts that as a KILL. A trained rule, or hardware that really skips work, would be needed to turn graded activity into a benefit.

## 3. Silent thinking steps (test LATENT-1)

**What we asked.** Brains think between inputs. If, at the end of each line of text, we give the model eight silent steps in which its own final hidden state is fed back as the next input (no word is produced), does it predict the next line better?

**What we did.** 16 blocks of 256 tokens from two public-domain books, decoded token by token with the model's cache. 289 line ends. Arms: no steps; the model's own state fed back, rescaled to the size of a normal input; the raw state; random vectors of the same size; the line-break token repeated eight times; and steps only after a harder-than-average line.

**What we found (FACT).** Mean loss per token (lower is better): no steps 3.270; own state, rescaled 4.038; raw state 4.398; random vectors 4.215; repeated line break 3.394; harder-lines-only 3.555. Feeding the model's own state back made the prediction 23.5 percent worse (interval 19.8 to 28.4 percent worse). It was slightly better than random vectors (5.4 points, interval 0.01 to 9.4) and far worse than repeating the line break (19.7 points). A check that the cached token-by-token decoding matches the normal pass passed (difference under 2e-6 per token).

**What it means (GUESS).** Looping a state back without training does not give "thinking in the state". Published methods that do (for example **PUBLISHED**: Hao et al. 2024, [Training Large Language Models to Reason in a Continuous Latent Space](https://arxiv.org/abs/2412.06769)) train the model for it. We have not trained a variant.

## 4. A lens into the model's inner guesses (test LENS-1)

**What we asked.** Can a small trained translator per layer read what the model is leaning toward at a middle layer? This is the "tuned lens" idea (**PUBLISHED**: Belrose et al. 2023, [Eliciting Latent Predictions from Transformers with the Tuned Lens](https://arxiv.org/abs/2303.08112)).

**What we did.** One affine translator at each of layers 3, 6, 9, 12, 15, 18 and 21, trained for 12 minutes (432,128 tokens, 25 public-domain books) to match the model's own final prediction. One further book was held out for scoring. The written bar: error at layer 18 at most 1.35 times the last layer's, at layer 12 at most 2.2 times, and every translator better than the untrained lens.

**What we found (FACT).** Held-out loss per token (last layer 3.12): layer 3: 5.79 (untrained 13.56); layer 12: 5.35 (1.71 times the last layer); layer 18: 4.58 (1.47 times); layer 21: 4.13 (1.32 times). The share of tokens where the lens guess matched the final guess rose from 31 percent at layer 3 to 66 percent at layer 21. Layer 12 and "better than untrained" passed; layer 18 missed its bar. The registered verdict is LENS FAIL, and we did not re-train to chase the bar. Training stopped at its time budget, not because the loss had levelled off, so a longer run could do better; we have not tried one.

## 5. A direction cue from two ears (test EAR-3)

**What we asked.** The brainstem compares the arrival time and loudness of a sound at the two ears. Do those two cues recover the direction of a sound if the answer is known?

**What we did.** Signals generated by code: 1 second of pink noise per trial, placed at seven directions from -60 to +60 degrees with a standard head model for the time difference and a level difference above 1 kHz, with noise added at 10, 5 and 0 dB signal-to-noise. 20 trials per direction, 100 millisecond frames. The readout cross-correlated the two ears in eight low-frequency bands and fitted a direction.

**What we found (FACT).** Median error: time and level together 1.0, 2.0 and 2.5 degrees at 10, 5 and 0 dB; level alone 8.5, 15.5 and 22.0; a random guess 38 to 39. Time alone was slightly better than time and level together (the noisy level term adds error). With two sounds at once the readout failed: only 1 percent of frames showed two peaks.

**What it does not show.** The readout uses the same head model that generated the signals, so this shows the cue extraction works, not that it works for real heads, rooms or soundtracks. Separating two sources needs a different analysis.

## 6. Can the small glance see? (tests PERC-1 and PERC-2)

**What we asked.** The small image input of our eye pipeline is 448 by 192 pixels, which becomes 84 picture tokens. Earlier tests with free-text answers did not tell whether it carries picture content, because most answers were not in a usable format. A fair format is to score each possible answer by the model's own probabilities.

**Generated shapes (PERC-1).** 800 pictures made by code: colour of a shape, shape, number of circles (one to four), and left or right. Four arms: the picture, a grey picture, the picture of a different item, and no picture. Accuracy with the picture: 0.8B 1.00, 1.00, 0.99 and 1.00 on the four question types; 2B 1.00 on all four. With a grey picture or no picture, both models sat exactly at chance; with the wrong picture they scored 0.00, because they followed the picture they were shown. Reading: SEES-BASIC for both models.

**Everyday photographs (PERC-2).** 500 photographs from the public COCO 2017 validation set (**PUBLISHED**: [COCO](https://cocodataset.org); captions typed by crowd workers. Secondary sources describe the annotations as CC BY 4.0 and the photos as subject to Flickr's terms and per-image licences; we did not retrieve the official terms text in this pass. We use the photos for research only and do not redistribute them), shown through the same glance, letterboxed. The model chooses among four human captions (its own plus three from other photos), scored by the picture-conditioned minus the text-only caption probability. Correct: 98.2 percent for the 0.8B model (interval 96.6 to 99.1) and 98.8 percent for the 2B model (97.4 to 99.5); chance is 25 percent. Controls: grey picture 26 and 25 percent, wrong picture 26 and 27 percent, language alone 23 and 24 percent. Reading: SEES-NATURAL for both models.

**What it does not show.** The wrong captions were random captions of other photos, which is an easy task; photographs are not video frames; the pictures are still; nothing about faces or text. The result says the picture content reaches the language side, which was not certain before. **Correction added 7 November 2026:** COCO photographs are widely copied on the web and the training data of these models is not disclosed, so it is plausible, and not checked, that the models have met these photographs and captions. The controls show the picture is needed; they do not separate seeing from remembering. A later control on fresh photographs (document 29, section 5) found the hard version of this task about 15 points lower on photos the models cannot have seen, still far above chance. See [document 29](29-a-harder-photo-test-a-fovea-and-a-caption-side-pass.md).

## What we could not conclude, and caveats

- **Small, indicative tests.** One model family, two sizes, one prompt style. The text tests use 8 to 16 blocks of 256 tokens, so differences below about half a percent in loss are not separated. The photo test has 500 items.
- **Registration.** Every test had its rules fingerprinted before its script ran. Two items changed afterwards, both before any model result existed: the generated-shapes test failed twice before producing any model answer (once on the length of a picture-token mask, once because four circles could not be placed at random), and was fixed with new script versions. In the drive-set test, we declared four small adaptations (the input-size measure, where the surprise signal comes from, the tolerance on the realised share, and how the budget scale is fixed) before running; none used a result.
- **Different cards and precision.** The 0.8B eye tests ran in 32-bit numbers on one card and the 2B tests in 16-bit numbers on another. We did not separate precision effects.
- **Not tested.** Speed of any kind; trained versions of the budget rule, the silent steps and the lens; video; sound with words.
- **AI-assisted.** The work is carried out with an AI assistant under the repository owner's direction. Nothing here has been peer reviewed.

## Label legend

- **FACT**: measured by our runs, with the setting and sample size given where we have them.
- **COMPUTED**: arithmetic on measured or stated numbers.
- **PUBLISHED**: from a named published source, with a link where one is given.
- **GUESS**: our reasoning, or anything beyond the tests.
- Verdict words such as KILL, LENS FAIL, SEES-BASIC and SEES-NATURAL are the written rules' own labels. A missed bar is reported as a miss.

Where a claim could take two labels, we use the more cautious one.
